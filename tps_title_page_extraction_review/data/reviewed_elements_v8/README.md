# Reviewed Elements-Oriented V8 Data

Main file:

`v8_results_preview_reviewed.csv`

This is the final manually reviewed V8 title-page extraction output for the older Elements-oriented batch. It covers 217 editions and 22 features. It is the safer file to use when asking questions specifically about the old Euclid/Elements corpus.

## Files

- `v8_results_preview_reviewed.csv`: reviewed extraction rows.
- `v8_feature_summary.csv`: V8 feature coverage summary.
- `v7_feature_summary.csv`: V7 feature coverage summary, kept to compare extraction-shape changes.

## Important Contrast

Do not treat this as representative of the whole larger mathematical-book corpus. This batch is heavily Euclid/Elements-oriented, so claims like "Euclid is nearly always present" or "base designation is stable" can be true here while failing in the larger corpus.

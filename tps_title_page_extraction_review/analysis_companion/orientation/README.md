# Orientation Files

These files define the companion's stance, data map, terms, and open questions. They are meant to be read before continuing analysis, especially after a break.

## Recommended Reading Order

1. `../CURRENT_STATUS.md`
2. `COMPANION_BRIEF.md`
3. `DATA_MAP.md`
4. `ANALYSIS_TERMS.md`
5. `CORRECTIONS_AND_NEXT_ANALYSIS_AGENDA.md`
6. `ANALYSIS_PLAN.md`

## Files

| File | Purpose |
|---|---|
| `COMPANION_BRIEF.md` | Role, stance, and guardrails for the analysis companion. |
| `DATA_MAP.md` | Data sources, metadata locations, and denominator warnings. |
| `ANALYSIS_TERMS.md` | Working definitions for recurring analytical terms. |
| `CORRECTIONS_AND_NEXT_ANALYSIS_AGENDA.md` | Important corrections to earlier exploratory assumptions. |
| `ANALYSIS_PLAN.md` | High-level research plan. |
| `QA_MAP_AND_NEXT_ROUTES.md` | Map of questions investigated and possible routes forward. |
| `QUESTION_LOG.md` | Running log of questions and findings. |
| `ARGUMENTS.md` | Working argument fragments. |
| `CASEBOOK.md` | Running case collection. |

# Old Presentation Audit

Critical audit of the March 2026 title-page presentation against the newer larger-corpus analysis.

Files:

- `title_page_presentation_extracted.txt`: text extracted from `presentation_context/Title Page Presentation.pdf`.
- `OLD_PRESENTATION_ARGUMENT_AUDIT.md`: claim-by-claim audit with verdicts, evidence, and suggested follow-up experiments.
- `PRESENTATION_ENRICHMENT_CANDIDATES.md`: newer arguments that can naturally enrich the old presentation.
- `NON_ELEMENTS_EUCLID_ELEMENTS_PROFILE.md`: profile of non-Elements books that nevertheless use Euclid/Elements language.
- `JESUIT_MARKED_ELEMENTS_PROFILE.md`: profile of Jesuit-marked Elements editions and how they differ from other Elements editions.
- `JESUIT_NON_ELEMENTS_COMPARISON.md`: comparison of Jesuit-marked Elements with Jesuit-marked non-Elements mathematical books.
- `FOLLOWUP_EXPERIMENTS_PLAN.md`: roadmap for the follow-up experiments, with first outputs noted.
- `LOCAL_CIRCULATION_NETWORK_SUMMARY.md`: Experiment 4 summary on Elements city/language centers, reprint routes, translation paths, and revised circulation claims.
- `non_elements_euclid_or_elements_cases.csv`: all non-Elements cases with Euclid/Elements language.
- `non_elements_euclid_or_elements_cases_classified.csv`: same cases with provisional route labels.
- `experiment_outputs/`: follow-up experiment CSVs and figures, including `local_circulation_network/`.
- `scripts/`: scripts used to generate audit/experiment outputs, including the local-circulation and named-adapter profile analyses.

## Historical Reading

These cases are important because they show that Euclid did not only live inside editions of the *Elements*. Euclid/Elements language could do several jobs outside the metadata-defined corpus:

1. **Foundation:** practical geometries invoke Euclid as the basis for measuring, surveying, and geometrical operations.
2. **Extract:** particular books, propositions, or doctrines circulate independently.
3. **Method:** Euclid names an order of proof or demonstrative discipline.
4. **Authority:** Euclid authorizes newer mathematical systems, even when the book is not an Elements edition.
5. **Template:** "Elements" becomes a form for organizing geometry or mathematics more generally.
6. **Bridge:** non-Elements practical books can be strongly Euclidean, while Elements editions can be practical or pedagogical.

This strengthens the report's boundary argument: the metadata Elements corpus remains distinctive, but Euclidean functions travel across the broader mathematical ecology.

## Caution

Some cases may be borderline metadata issues rather than historical "outside" cases. The metadata-defined Elements corpus is complete for the Elements editions currently identified in the metadata, including reprints, but this non-Elements Euclid/Elements set is exactly where we should inspect boundaries and decide whether a few keys should be reclassified or treated as meaningful adjacent works.

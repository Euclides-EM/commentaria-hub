# Report Casebook Shortlist

Date: 2026-06-12

Purpose:

This is the human-facing casebook for the report. It is not a list of every interesting edition. Each case has one main job in the argument, so the report can stay readable and avoid using the same example to prove everything.

Use this casebook when drafting. The main prose should introduce each case in ordinary historical language, then send technical details to appendices or tables.

## How To Use Cases In The Report

Rules:

1. Give each case one job.
2. Explain the job before giving the evidence.
3. Translate internal labels into historical language.
4. Do not cite a case only because it is colorful; cite it because it changes or sharpens the claim.
5. For every quoted title-page phrase, verify against the row evidence before final use.

## Section By Section Use

### Section 2: Surrounding Mathematical Print Ecology

Primary cases:

- `bib-86`: many explicit professional users.
- `bib-135`: practical geometry for professions and lovers.
- `bib-9`: practical geometry derived from Euclid.

Claim they support:

The surrounding ecology is not a neutral background. It advertises mathematical work through users, professions, instruments, practical operations, visual aids, and utility. Some of it is explicitly Euclidean, but it does not usually present itself as the restored Elements.

### Section 3: Locating The Elements Within The Ecology

Primary cases:

- `Paris_1622`;
- `Rotterdam_1647`;
- `bib-9`;
- `Cambridge_1703`.

Claim they support:

The Elements sits inside a gradient. At one end is Euclid as restored/corrected translated corpus; at another are non-Elements practical works that use Euclid as a foundation or authority. Between them are usable Elements and Euclidean practical geometry.

### Section 4-5: Internal Ecology And Book Coverage

Primary cases:

- `Rotterdam_1647`;
- `Amsterdam_1700b` / `Amsterdam_1701`;
- `London_1685a`;
- `Oxford_London_1700`;
- `Cologne_1556`.

Claim they support:

The metadata-defined Elements corpus is internally differentiated. Plain `1-6`, `1-6 + 11-12`, selected books, and near-complete editions do different work. The difference is not only how much Euclid they include, but what kind of Euclid they make usable.

### Section 6: Social Worlds

Primary cases:

- `Rotterdam_1647`: public lovers plus surveyor/wine-gauger authority.
- `London_1685a`: Jesuit author, English translator, practical-pedagogical package.
- `Cologne_1591` / `Frankfurt_1607`: Jesuit/institutional authority.
- `bib-86`: explicit professional users outside the Elements.

Claim they support:

Social address shapes intellectual mediation. The same Euclid can be authorized by humanist scholarship, religious/institutional authority, public vernacular readership, professional practice, or translation/editing labor.

### Section 7: Intellectual Values

Primary cases:

- `Paris_1536`: ancient/canonical demonstration.
- `Urbino_1575`: vernacular humanist learned Euclid.
- `Paris_1622`: translation, correction, figures, demonstrations.
- `Rome_1591` / `Rome_1609`: ancient scholia and learned recovery.
- `London_1570`: vernacular mediation, scholies, annotations, inventions.

Claim they support:

Elements title pages value Euclid as a corpus to be mediated: restored, translated, corrected, explained, furnished, commented, demonstrated, and sometimes repackaged for use.

### Section 8: Mathematical Parts

Primary cases:

- `London_1685a`: propositions as usable/application units.
- `Paris_1640`: propositions reduced and demonstrations made easier/shorter.
- `Rome_1591` / `Rome_1609`: scholia, figures, annotations, translation.
- `Rotterdam_1647`: figures and geometrical operations.
- `Cambridge_1703`: corollaries, applications, diagrams in an Elements-like geometry.

Claim they support:

Title pages do not just name mathematical subjects; they advertise the working parts of mathematics. In Elements editions, propositions, demonstrations, scholia, figures, and corollaries become tools for different intellectual programs.

### Section 9: Restoration And Reconstruction

Primary cases:

- `Paris_1667`;
- `Livorno_1709`;
- `Paris_1640`;
- `Cologne_1556`.

Claim they support:

Reconstructive Euclid is not simply anti-ancient. It can claim to restore the logic, order, clarity, demonstrative force, or teachability of Euclid rather than the ancient wording alone.

### Section 10: Boundaries And Gradients

Primary cases:

- `Paris_1622`: canonical but vernacular and usable.
- `Rotterdam_1647`: Elements but practical/public.
- `bib-9`: not Elements but explicitly Euclidean.
- `Cambridge_1703`: Elements-like, Euclid-adjacent geometry.
- `bib-135`: practical geometry without being an Elements edition.

Claim they support:

The boundary of the Elements is stable as metadata corpus but flexible as intellectual ecology. Early modern print lets Euclid appear as text, method, foundation, authority, school object, practical extraction, and mathematical style.

## Cases To Use Sparingly

These are useful, but should not become central:

- Author/editor portfolio cases: use only where close title-page comparison is possible, because we do not have full bibliographies.
- Wardhaugh/textual family labels: do not use as report evidence.
- Sparse-canonical cases: use only with format, region, language, and period controls.
- General Euclid/Elements title-language cases: useful for comparison, but not the report's corpus definition.

## Human-Friendly Translation Of Internal Labels

Use these translations in prose:

| Internal Label | Human-Friendly Phrase |
|---|---|
| `metadata Elements` | editions manually identified in the metadata as primarily Euclid's Elements |
| `canonical_elements` | Euclid as restored, authoritative, textual corpus |
| `usable_elements` | Euclid made teachable, portable, practical, or pedagogically useful |
| `euclidean_practical_geometry` | non-Elements practical geometry that invokes Euclid or the Elements |
| `professional_material_practical_arts` | mathematical print for instruments, measurement, construction, commerce, military or visual practice |
| `euclid_composite_workshop` | apparatus-rich Euclid, furnished with additions, figures, commentary, or related texts |
| `practical-pedagogical` | Euclid framed through teaching, use, method, propositions, or application |
| `humanist/vernacular transfer` | translation as learned recovery and cultural transfer, not merely simplification |
| `near_complete_or_expanded` | editions that present most or all of the Elements, often with added apparatus or related material |
| `books_1_6_plus_solids` | editions combining the first six books with solid geometry, usually books 11-12 |

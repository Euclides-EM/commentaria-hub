EUCLID’S ELEMENTS.

I strongly urge [you] to read with zeal those who have written on Euclid, so that all who indeed desire to be mathematicians may do so; to whom I shall never deny that I owe very much. As to the matter, it is of this kind: that first principle of Campanus seems at least to comprehend every quantity (whether it be that which they call continuous, or whether it be discrete such as number is). Moreover there is something else which belongs only to continuous quantity: that you can diminish it to infinity, as in a line. For whatever [line] is given, it can be divided into infinite parts, whether it can be divided or not, and yet each part will be a line; and that again into others which retain the same nature; nor is it ever reached, by section, to a minimum—not even if you should call it a point, although that in itself is the minimum in geometry. Hence it comes about that there are certain irrational lines, among which indeed there is some proportion to one another, but it cannot be expressed by number; and therefore it is called by Proclus ἄλογος ὀξὺς τομ. For wherever there is section or division to infinity, there too is found that ineffable thing which they call ἄλογον; but this is not so in numbers. For there is no number which, by dividing, you do not reduce to that minimum which is unity, from which it is agreed that all numbers must be. For unity measures all. Therefore there are no irrational numbers. But as to the exposition of the following theorems, note this: that it was not our plan, at the beginning of the work undertaken, to apply our hand to each one. And then indeed to do this seemed [enough], if I should copy for myself those things which have been correctly handed down by the ancients (and they are many).

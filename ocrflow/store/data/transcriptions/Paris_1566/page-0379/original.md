Sit pentagoni A B C D E perpendicularis A G, ſubtendens verò angulum pentagoni, eſto A C. Quoniam A C recta latus eſt cubi, dodecahedri verò latus eſt C D eadem ſphæra deſcriptorum, per coroll. ſecundum decimæſeptimæ decimitertij. Sed A C dimetienti ſphæræ eſt commenſurabilis, per 15 decimitertij, & ideo certa, per ſextam diffinitionem decimi. Recta verò C D (dodecadri latus) incerta eſt, per 17 decimitertij. Quare C G eius dimidia incerta erit, per 103 decimi. Binas autem A G G C poteſt A C, per 47 primi. Si itaque à potentia rectæ A C certæ, potentia ipſius C G incertæ tollatur, quæ ſupererit (potentia quidem rectæ A G) incerta erit neceſſariò. Nam ſi A G ablata certa eſſet, & tota A C certa, reliqua C G certa eſſet, nempe iiſdem numeris menſa, per ſecundam communem ſententiam ſeptimi. Sed incerta oſtenſa fuit C G, dimidia nanque totius C D apotome, per 17 decimitertij, quod fieri non poteſt, incerta igitur erit & A G perpendicularis, per vndecimam diffinitionem decimi. Angulus igitur inclinationis dodecahedri, ſub binis pentagoni perpendicularibus comprehenſus, quẽ inſuper ſubtendit recta coniungens bifarias oppoſitorum dodecahedri laterum ſectiones, per ſecundum coroll. 18 decimitertij, quam incertam eſſe docuimus, cùm fuerit æqualis binis A C C D, per coroll. quartum decimæſeptimæ decimitertij, ſub incertis dicetur contineri lineis rectis.

## PROP. XIV.

[Diagram: four vertical lines labelled A, B, C, D]

*Si prima* A *ad ſecundam* B *eandem habuerit rationem, quàm tertia* C *ad quartam* D; *prima verò* A, *quàm tertia* C *major fuerit, erit & ſecunda* B *major quàm quarta* D. *Quòd ſi prima* A *fuerit æqualis tertiæ* C, *erit & ſecunda* B *æqualis quartæ* D; *ſi verò* A *minor, &* B *minor erit.*

Sit A ⊏ C. ᵃ

[Margin]
a 8. 5.
[/Margin]

ergò A/B ⊏ C/B. ᵇ

[Margin]
b hyp.
[/Margin]

ſed A/B = C/D. ᶜ

[Margin]
c 13. 5.
[/Margin]

ergò C/D ⊏ C/B. ᵈ ergò B ⊏ D. Simili argumento ſi A ⊐ C, ᵈ

[Margin]
d 10. 5.
[/Margin]

erit B ⊐ D. Sin ponatur A = C; ergò C.B ᵉ

[Margin]
e 7. 5.
[/Margin]

:: A.B ᶠ

[Margin]
f hyp.
[/Margin]

:: C.D. ᵍ

[Margin]
g 4.5 & 9.5.
[/Margin]

ergò B = D. Quæ E. D.

### *SCHOL.*

A fortiori, ſi A/B ⊐ C/D, atque A ⊏ C, erit B ⊏ D. Item ſi A = B; erit C = D. Et ſi A ⊏, vel ⊐ B, erit pariter C ⊏, vel ⊐ D.

## PROP. XV.

[Diagram: vertical lines labelled B, G, A, C and E, H, D, F]

*Partes* C & F *cum pariter multiplicibus* AB, & DE *in eadem ſunt ratione; ſi prout ſibi mutuò reſpondent, ità ſumantur.* ( AB. DE :: C.F. ).

Sint AG, GB partes multiplicis AB ipſi C æquales: item DH, HE partes multiplicis DE ipſi F æquales. ᵃ

[Margin]
a hyp.
[/Margin]

Harum numerus illarum numero æquatur. ergò quum ᵇ

[Margin]
b 7. 5.
[/Margin]

AG. C :: DH. F; ᵇ atq; GB. C :: HE. F. ᶜ

[Margin]
c 12. 5.
[/Margin]

erit AG+GB ( AB ). DH+HE ( DE ) :: C.F. Q. E. D.

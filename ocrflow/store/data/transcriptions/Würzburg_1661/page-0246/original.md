Quæ quidem duo triangula ſunt omnino æquiangula. Nam angulus ad B ſeu b eſt communis utriq; triangulo, angulus b a c parvi eſt idem cum angulo B A C magni; angulus deniq; a c b eſt æqualis angulo A C B, per 32. pri. Ergo, per 4. Sexti, latera quæ æqualibus adjacent angulis, ſunt inter ſe proportionalia; & latera quæ æqualibus angulis opponuntur, ſunt homologa.

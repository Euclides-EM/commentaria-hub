Car soit O le point de concours des droites AB, CD ; dans le triangle OEF, où la ligne AC est menée parallélement à la base, on aura OE : AE :: OF : CF, ou OE : OF :: AE : CF. Dans le triangle OGH, on aura semblablement OE : EG :: OF : FH, ou OE : OF :: EG : FH. Donc, à cause du rapport commun, OE : OF, ces deux proportions donnent AE : CF :: EG : FH. On démontrera de la même maniere qu’on a EG : FH :: GB : HD, et ainsi de suite. Donc les lignes AB, CD, sont coupées proportionnellement par les paralleles EF, GH, etc.

## PROPOSITION XVI.

### THÉORÊME.

[Margin]
F. 116.
[/Margin]

*Réciproquement si les côtés AB, AC, sont coupés proportionnellement par la ligne DE, de sorte qu’on ait AD : DB :: AE : EC, je dis que la ligne DE sera parallele à la base BC.*

Car si DE n’est pas parallele à BC, supposons que DO le soit ; alors, suivant le théorême précédent, on aura AD : BD :: AO : OC. Mais par hypothese AD : DB :: AE : EC ; donc on auroit AO : OC :: AE : EC ; proportion impossible, puisque d’une part l’antécédent AE est plus grand que l’antécédent AO, et que de l’autre le conséquent EC est plus petit que OC. Donc la parallele à BC menée par le point D ne peut différer de DE ; donc DE est cette parallele.

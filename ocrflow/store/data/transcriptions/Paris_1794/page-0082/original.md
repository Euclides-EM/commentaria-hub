### PROBLÊME XVII.

*Trouver le rapport numérique de deux lignes droites données AB, CD, si toutefois ces deux lignes ont entre elles une mesure commune.*

[Margin]
Fig. 90.
[/Margin]

Portez la plus petite CD sur la plus grande AB autant de fois qu’elle peut y être contenue, par exemple, deux fois, avec le reste BE.

Portez le reste BE sur la ligne CD autant de fois qu’il peut y être contenu, une fois, par exemple, avec le reste DF.

Portez le second reste DF sur le premier BE, autant de fois qu’il peut y être contenu, une fois par exemple, avec le reste BG.

Portez le troisième reste BG sur le second DF autant de fois qu’il peut y être contenu.

Continuez ainsi jusqu’à ce que vous ayez un reste qui soit contenu un nombre de fois juste dans le précédent.

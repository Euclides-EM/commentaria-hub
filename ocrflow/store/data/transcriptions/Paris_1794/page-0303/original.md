## PROPOSITION XVII.

### PROBLÈME.

*Le segment circulaire BMD étant supposé faire une révolution autour du diametre AG extérieur à ce segment, trouver la valeur du solide engendré.*

[Margin]
F. 273.
[/Margin]

Abaissez sur l’axe les perpendiculaires BE, DF ; menez CI perpendiculaire sur la corde BD ; et tirez les rayons CB, CD.

Le solide décrit par le secteur BCA = ⅔ π. CA². AE* ;

[Margin]
* 15.
[/Margin]

le solide décrit par le secteur DCA = ⅔ π. CA². AF ; donc la différence de ces deux solides, ou le solide décrit par le secteur DCB = ⅔ π. CA². (AF − AE) = ⅔ π. CA². EF. Mais le solide décrit par le triangle isoscele DCB a pour mesure ⅔ π. CI². EF* ;

[Margin]
* 13.
[/Margin]

donc le solide décrit par le segment BMD = ⅔ π. EF. (CA² − CI²). Or dans le triangle rectangle CBI on a CB² − CI² = BI² = ¼ BD² ; donc, à cause de CA = CB, le solide décrit par le segment BMD aura pour mesure ⅔ π. EF. ¼ BD², ou ⅙ π. BD². EF.

on pourra mettre *a*/(*z* ψ : *z*), et ((*z* + 1) ψ : (*z* + 1))/*a* au lieu de (φ : (*z* + 2))/(φ : (*z* + 1)). La substitution faite, on aura ψ : *z* = *a*/(*z* + ψ : (*z* + 1)).

Mais en mettant successivement dans cette équation *z* + 1, *z* + 2, etc., à la place de *z*, il en résultera

[Calculation]
ψ : (*z* + 1) = *a*/(*z* + 1 + ψ : (*z* + 2)), ψ : (*z* + 2) = *a*/(*z* + 2 + ψ : (*z* + 3)), etc.
[/Calculation]

Donc la valeur de ψ : *z* peut s’exprimer ainsi en fraction continue :

[Calculation]
ψ : *z* = *a*/(*z* + *a*/(*z* + 1 + *a*/(*z* + 2 +, etc.)))
[/Calculation]

Réciproquement cette fraction continue, prolongée à l’infini, a pour somme ψ : *z*, ou son égale *a*/*z* · (φ : (*z* + 1))/(φ : *z*); et cette somme, développée en suites ordinaires, est

[Calculation]
*a*/*z* · (1 + *a*/(*z* + 1) + ½ · *a*²/((*z* + 1) · (*z* + 2)) +, etc.)/(1 + *a*/*z* + ½ · *a*²/(*z* · (*z* + 1)) +, etc.)
[/Calculation]

Soit maintenant *z* = ½, la fraction continue deviendra

[Calculation]
2*a*/(1 + 4*a*/(3 + 4*a*/(5 +, etc.)));
[/Calculation]

de sorte que ses numérateurs, excepté le premier, seront égaux à 4 *a*, et ses dénominateurs formeront la suite des nombres impairs 1, 3, 5, 7, etc. La valeur de cette fraction continue peut donc aussi s’exprimer par

[Calculation]
2*a* · (1 + 4*a*/(2 · 3) + 16*a*²/(2 · 3 · 4 · 5) + 64*a*³/(2 · 3 ··· 7) +, etc.)/(1 + 4*a*/2 + 16*a*²/(2 · 3 · 4) + 64*a*³/(2 · 3 ··· 6) +, etc.).
[/Calculation]

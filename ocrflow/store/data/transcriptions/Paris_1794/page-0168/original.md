# LIVRE V.

[Ornament]

[Subhead]
LES PLANS ET LES ANGLES SOLIDES.
[/Subhead]

[Ornament]

## DÉFINITIONS.

[Margin]
* Pr. 4.
[/Margin]

[Curated heading level=1 type=definitions: Livre V]

[Curated heading level=2 type=definitions: Définition I.]

[Curated heading level=3 type=numbered_item: 1.]

I. {dropcap:U|lines=2|style=plain}NE ligne droite est perpendiculaire à un plan, lorsqu’elle est perpendiculaire * à toutes les droites qui passent par son pied dans le plan. Réciproquement le plan est perpendiculaire à la ligne.

Le pied de la perpendiculaire est le point où cette ligne rencontre le plan.

[Curated heading level=2 type=definitions: Définition II.]

[Curated heading level=3 type=numbered_item: 2.]

II. Une ligne est parallele à un plan, lorsqu’elle ne peut le rencontrer à quelque distance qu’on les prolonge l’un et l’autre. Réciproquement le plan est parallele à la ligne.

[Curated heading level=2 type=definitions: Définition III.]

[Curated heading level=3 type=numbered_item: 3.]

III. Deux plans sont paralleles entre eux, lorsqu’ils ne peuvent se rencontrer à quelque distance qu’on les prolonge l’un et l’autre.

[Margin]
* Pr. 5.
[/Margin]

[Curated heading level=2 type=definitions: Définition IV.]

[Curated heading level=3 type=numbered_item: 4.]

IV. Il sera démontré * que l’intersection commune de deux plans qui se rencontrent est une ligne droite : cela posé, l’inclinaison mutuelle de deux plans se mesure * par l’angle que font entre elles les deux perpendiculaires menées dans chacun de ces plans au même point de l’intersection commune.

[Margin]
* Pr. 17.
[/Margin]

Cet angle peut être aigu, droit ou obtus.

[Curated heading level=2 type=definitions: Définition V.]

[Curated heading level=3 type=numbered_item: 5.]

V. S’il est droit, les deux plans seront perpendiculaires entre eux.

                 The aim of the Tenth Book.

Let some magnitude be able to be multiplied so many times,
until it surpasses some magnitude of the same kind.

When therefore two unequal magnitudes of the same kind are set forth,
whose size is not unlimited, it is evident that the smaller can be
multiplied so many times, until it surpasses the greater.
But those same magnitudes are also said to be of the same kind, as
a line with a line, and a plane with a plane, and a body with a body;
likewise a number with a number. The same also has place in all kinds
of magnitudes, as sounds, times, weights etc.

            The Common Notions of the tenth Book.

                    The first Common Notion.

A magnitude measuring some magnitudes, also measures the composite
magnitude from the same.

This Common Notion has the same reason in magnitudes, as the tenth Common
Notion of the seventh Book in numbers.

                    The second Common Notion.

A magnitude measuring some magnitude, also measures that magnitude, which the
magnitude measures.

This Common Notion has the same nature in magnitudes, as the eleventh Common
Notion of the seventh Book in numbers.

## QUATRIEME THEOREME.

[Margin]
XV.
[/Margin]

Trois raiſons de nombre à nombre eſtant égales, la raiſon du produit des 3 antecedens au produit des 3 conſequens a pour ſes expoſans des nombres cubiques.

### PREMIERE PREUVE.

Chacune des 3 raiſons égales eſtant reduite aux moindres termes, elles ſe trouvent reduites aux mêmes nombres.

[Calculation]
bx.   cx  ::  by.   cy  ::  bz.   cz.
b.    c   ::  b.    c   ::  b.    c.
[/Calculation]

[Calculation]
Donc le produit  { des antecedens   bbb.
                 { des conſequens   ccc.
[/Calculation]

### SECONDE PREUVE.

*Sans cette reduction en parcourant les 3 manieres.*

### PREMIERE MANIERE.

[Calculation]
b.   bx  ::  c.   cx  ::  d.   dx.
[/Calculation]

Ajoûtant l'unité aux antecedens

[Calculation]
bi.  bx  ::  ci.  cx  ::  di.  dx.
[/Calculation]

[Calculation]
Donc le produit  { des antecedens   bicidi.
                 { des conſequens   bxcxdx.
Donc oſtant de part & d'autre bcd , reſte  { iii.
                                           { xxx.
[/Calculation]

### SECONDE MANIERE, qui eſt meſlée de la Troiſiéme.

[Calculation]
b.   c  ::  bx.   cx  ::  by.   cy.
[/Calculation]

ajoûtant l'unité aux deux premiers termes

[Calculation]
bi.  ci  ::  bx.  cx  ::  by.  cy.
[/Calculation]

[Calculation]
Donc le produit  { des antecedens   bibxby.
                 { des conſequens   cicxcy.
Donc oſtant de part & d'autre ixy , reſte  { bbb.
                                           { ccc.
[/Calculation]

C'eſt la même choſe de la 3e maniere.

## PROPOSITION FONDAMENTALE
### DES GRANDEVRS INCOMMENSVRABLES.

[Margin]
XVI.
[/Margin]

La raiſon doublée ou triplée d'une raiſon de nombre à nombre , eſt auſſi une raiſon de nombre à nombre , qui a pour ſes expoſans des nombres quarrez ſi elle eſt doublée , & des nombres cubiques ſi elle eſt triplée.

D'où il s'enſuit qu'une raiſon ſimple n'eſt pas de nom-

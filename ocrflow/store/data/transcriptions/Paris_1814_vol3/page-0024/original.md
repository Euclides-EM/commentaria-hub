<!-- Running title: PRÆFATIO. -->

Sed rectangulum ΑΒ × ΒΓ datum est (lemma), nec non rectangulum ΒΓ × ΒΔ; ratio igitur ipsius ΑΒ × ΒΓ ad ipsum ΒΓ × ΒΔ data est. Sit autem ratio ipsius ΑΒ × ΒΓ ad ΒΓ × ΒΔ eadem quæ ratio ipsius *m* ad *o*;

Ergo ΑΒ × ΒΓ : ΒΓ × ΒΔ :: *m* : *o*.

Sed ΑΒ × ΒΓ : ΒΓ × ΒΔ :: ΑΒ : ΒΔ;

Ergo ΑΒ : ΒΔ :: *m* : *o*;

Ergo ΑΒ² : ΒΔ² :: *m*² : *o*² : *m* : *p*.

Sed ΒΓ × ΔΓ : ΑΒ² :: *m* : *n* (A);

Ergo ΒΓ × ΔΓ : ΒΔ² :: *m*² : *n* × *p* :: *m* : *q*;

Ergo 4 ΒΓ × ΔΓ : ΒΔ² :: 4 *m* : *q*;

Ergo 4 ΒΓ × ΔΓ + ΒΔ² : ΒΔ² :: 4 *m* + *q* : *q* :: *m*² : *s*².

Sed 4 ΒΓ × ΔΓ + ΒΔ² = (ΒΓ + ΕΓ{printer-error-correction:ΔΓ})² (lib. II, prop. VIII);

Ergo (ΒΓ + ΔΓ)² : ΒΔ² :: *m*² : *s*²;

Ergo ΒΓ + ΔΓ : ΒΔ :: *m* : *s*;

Ergo ΒΓ + ΔΓ + ΒΔ, c'est-à-dire 2 ΒΓ : ΒΔ :: *m* + *s* : *s*;

Ergo (B) ΒΓ : ΒΔ :: (*m* + *s*)/2 : *s* :: *m*² : *t*².

Sed ΒΓ : ΒΔ :: ΒΓ × ΒΔ : ΒΔ²;

Ergo (C) ΒΓ × ΒΔ : ΒΔ² :: *m*² : *t*².

Sed ipsum ΒΓ × ΒΔ datum est; ipsum igitur ΒΔ² datum est; recta igitur ΒΔ est data; quare et ipsa ΒΓ data est. Sed ipsum ΑΒ × ΒΓ est datum, nec non angulus Β; quare et ipsa ΑΒ est data; rectæ igitur ΑΒ, ΒΓ datæ sunt.

Ex hoc manifestum est nos habituros esse valores rectarum incognitarum ΑΒ, ΒΓ ope duarum proportionum *B* et *C*. Etenim si, in proportione *C*, substituamus superficiem datam *a*² pro rectangulo ΒΓ × ΒΔ, habebimus ΒΔ = (*a* *t*)/*m*, et si substituamus hunc valorem ipsius ΒΔ, in proportione *B*, habebimus ΒΓ = (*a* *m*)/*t*.

Ex libris Hypsiclis, complures mendas crassissimas et solo ictu oculorum evidentissimas ejeci, quæ tamen in tribus codicibus 190, 2342, 2343 *, et in editionibus Basiliæ Oxoniæque reperiuntur. (*Vide* Lectiones varias.)

[Footnote]
* Hi tres codices, codice 2342 excepto, defectuosi sunt et lacunis scatentes.
[/Footnote]

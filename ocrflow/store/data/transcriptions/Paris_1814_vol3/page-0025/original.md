Mais le rectangle ΑΒ × ΒΓ est donné (lemme), ainsi que le rectangle ΒΓ × ΒΔ; la raison de ΑΒ × ΒΓ à ΒΓ × ΒΔ est donc donnée. Que la raison de ΑΒ × ΒΓ à ΒΓ × ΒΔ soit la mème que celle de *m* à *o*,

On aura ΑΒ × ΒΓ : ΒΓ × ΒΔ :: *m* : *o*.

Mais ΑΒ × ΒΓ : ΒΓ × ΒΔ :: ΑΒ : ΒΔ;

Donc ΑΒ : ΒΔ :: *m* : *o*;

Donc ΑΒ² : ΒΔ² :: *m*² : *o*² : *m* : *p*.

Mais ΒΓ × ΔΓ : ΑΒ² :: *m* : *n* (A);

Donc ΒΓ × ΔΓ : ΒΔ² :: *m*² : *n* × *p* :: *m* : *q*;

Donc 4 ΒΓ × ΔΓ : ΒΔ² :: 4 *m* : *q*;

Donc 4 ΒΓ × ΔΓ + ΒΔ² : ΒΔ² :: 4 *m* + *q* : *q* :: *m*² : *s*².

Mais 4 ΒΓ × ΔΓ + ΒΔ² = (ΒΓ + ΔΓ)² (liv. II, prop. VIII);

Donc (ΒΓ + ΔΓ)² : ΒΔ² :: *m*² : *s*²;

Donc ΒΓ + ΔΓ : ΒΔ :: *m* : *s*;

Donc ΒΓ + ΔΓ + ΒΔ, c'est-à-dire 2 ΒΓ : ΒΔ :: *m* + *s* : *s*;

Donc (B) ΒΓ : ΒΔ :: (*m* + *s*)/2 : *s* :: *m*² : *t*².

Mais ΒΓ : ΒΔ :: ΒΓ × ΒΔ : ΒΔ²;

Donc (C) ΒΓ × ΒΔ : ΒΔ² :: *m*² : *t*².

Mais ΒΓ × ΒΔ est donné; ΒΔ² est donc donné aussi; la droite ΒΔ est donc donnée; la droite ΒΓ est donc donnée aussi. Mais ΑΒ × ΒΓ est donné, ainsi que l'angle Β; la droite ΑΒ est donc donnée aussi; les droites ΑΒ, ΒΓ sont donc données.

Il est évident, d'après cela, que l'on aura les valeurs des inconnues ΑΒ, ΒΓ par le moyen des deux proportions *B* et *C*. En effet, substituant, dans la proportion *C*, la surface donnée *a*² au rectangle ΒΓ × ΒΔ, on aura ΒΔ = (*a* *t*)/*m*, et substituant cette valeur de ΒΔ dans la proportion *B*, on aura ΒΓ = (*a* *m*)/*t*.

Dans les livres d'Hypsicle, j'ai fait disparaître une foule de fautes grossières qui sautaient aux yeux, et qui cependant se trouvaient dans les trois manuscrits 190, 2342, 2343 *, et dans les éditions de Bâle et d'Oxford. (*Voyez* les Variantes.)

<!-- Running title: PRÆFATIO. -->

Hæc est solutio algebrica theorematis LXXXVII, quod quidem in nullâ suarum partium vitiatum erat.

Duæ rectæ *x*, *y* contineant superficiem datam *c*², in angulo dato Β, et sit ut quadratum *x*² præter superficiem datam *a*² ad *y*² ita recta data *m* ad rectam datam *n*; dico rectas *x*, *y* datas fore.

Inveniemus superficiem æqualem rectangulo sub rectis *x*, *y* contento, ope hujus proportionis, *sin.* Β : R :: *c*² : (R × *c*²)/(*sin.* Β);

Ponatur quadratum *b*² æquale rectangulo (R × *c*²)/(*sin.* Β);

Fiet *xy* = *b*².

Sed *x*² — *a*² : *y*² :: *m* : *n*;

Ergo *nx*² — *na*² = *my*².

His duabus æquationibus resolutis, invenietur,

[Calculation]
x = √( a²/2 + √( (4 m b⁴ + n a⁴) / (4 n) ) )

y = √( − n a²/(2 m) + √( (4 m n b⁴ + n² a⁴) / (4 m²) ) ).
[/Calculation]

Talis est algebræ agendi modus; hic autem Euclidis. Utar signis abreviatoribus nostris, ut pro certo habeatur eorum utilitas in comprehendendis arduis quæstionibus antiquæ geometriæ.

[Diagram: parallelogram with vertices labelled Α, Β, Γ and point Δ on the base ΒΓ]

Ponatur rectangulum ΒΓ × ΒΔ æquale superficiei datæ *a*². Quoniam ΒΓ² = ΒΓ × ΒΔ + ΒΓ × ΔΓ; ergo ΒΓ² — *a*² = ΒΓ² — ΒΓ × ΒΔ = ΒΓ × ΔΓ.

Sed ΒΓ² — *a*² : ΑΒ² :: *m* : *n*;

Ergo (A) ΒΓ × ΔΓ : ΑΒ² :: *m* : *n*.

# EUCLIDIS ELEMENTORUM LIBER SEPTIMUS.

[Ornament]

## ΟΡΟΙ.

αʹ. Μονάς ἐστι, καθ᾽ ἣν ἕκαστον τῶν ὄντων ἓν λέγεται.

βʹ. Ἀριθμὸς δὲ, τὸ ἐκ μονάδων συγκείμενον πλῆθος.

γʹ. Μέρος ἐστὶν ἀριθμὸς ἀριθμοῦ, ὁ ἐλάσσων τοῦ μείζονος, ὅταν καταμετρῇ τὸν μείζονα.

## DEFINITIONES.

1. Unitas est secundum quam unumquodque existentium unum dicitur.

2. Numerus autem, ex unitatibus composita multitudo.

3. Pars est numerus numeri, minor majoris, quando metitur majorem.

# LIVRE SEPTIEME DES ÉLÉMENS D’EUCLIDE.

[Ornament]

## DÉFINITIONS.

1. L’unité est ce selon quoi chacune des choses existantes est dite une.

2. Un nombre est un assemblage composé d’unités.

3. Un nombre est une partie d’un nombre, le plus petit du plus grand, lorsque le plus petit mesure le plus grand.

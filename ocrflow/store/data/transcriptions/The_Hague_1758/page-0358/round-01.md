### HYPOTHESE.

*I. Le ⊟ ſur A eſt ∽ au ⊟ ſur B.*

*II. Item le ⊟ ſur C eſt ∽ au ⊟ ſur D.*

*III. Le ⊟ ſur A : ⊟ ſur B = ⊟ ſur C : ⊟ ſur D.*

### THESE.

*A : B = C : D.*

### II. DEMONSTRATION.

{dropcap:P|lines=2|style=plain}Uiſque le ⊟ ſur A eſt ∽ au ⊟ ſur B (*Hyp.* 1.)

1. Le ⊟ ſur A : ⊟ ſur B = A³ : B³.

[Margin]
Prop.33. L.11.
[/Margin]

De même le ⊟ ſur C eſt ∽ au ⊟ ſur D. (*Hyp.* 2.).

2. Le ⊟ ſur C : ⊟ D = C³ : D³.

[Margin]
Prop.33.L.11.
[/Margin]

Or le ⊟ ſur A : ⊟ ſur B = ⊟ C : ⊟ D. (*Hyp.* 3.).

3. Donc A³ : B³ = C³ : D³.

[Margin]
Prop. 11. L. 5.
Ax. 7. L 1.
[/Margin]

4. Partant A : B = C : D.

C. Q. F. D. II.

## REMARQUE.

I. {dropcap:P|lines=2|style=plain}*Uiſque le priſme triangulaire eſt la moitié de ſon paralelipipéde* (par la Propoſition 28. de ce Livre.) *Il s'enſuit* (par Ax. 7. L. 1.) *que la même vérité à lieu pour les priſmes triangulaires ſemblables.*

II. *On peut auſſi l'appliquer aux priſmes-polygones ſemblables ; puiſqu'ils peuvent être diviſés par des Plans en priſmes triangulaire partielles ,* (par la Remarque 2. de la Propoſition 34. de ce Livre ).

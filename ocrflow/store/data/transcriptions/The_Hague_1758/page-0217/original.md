## PROPOSITION XIV. THEOREME XIV.

{dropcap:S|lines=2|style=plain}I quatre grandeurs ( A, B, C, D ) ſont proportionelles : ſelon que la premiere ( A ) ſera plus grande, égale, ou moindre, que la troiſieme ( C ), la ſeconde ( B ) ſera auſſi plus grande, égale, ou moindre que la quatrieme ( D ).

HYPOTHESE.

I. A : B = C : D.
II. A eſt >, = ou < C.

THESE.

Se’on{printer-error-correction:Selon} que A eſt >, = ou < C.
B ſera >, = ou < D.

CAS I. Si A eſt > C.

### DEMONSTRATION.

1. {dropcap:L|lines=2|style=plain}A raiſon de A : B eſt donc > la raiſon C : B.
Mais A : B = C : D (*Hyp.* 1);
2. Donc la raiſon de C : D eſt > la raiſon C : B.
3. D’où il ſuit, que D eſt < B ou B > D.
On démontrera de la même maniere pour les deux autres cas; ſi A = C, que B ſera = D; & ſi A eſt < C, que B ſera < D.
4. Par conſéquent, ſelon que A eſt >, =, ou < C, pareillement B eſt >, =, ou < D.

# D'EVCLIDE, LIV. III.

(ornament)

LE TROISIESME LIVRE DES ELEMENTS D'EVCLIDE.

# DEFINITIONS.

I.

CERCLES égaux sont ceux desquels les diametres sont égaux ; ou desquels les lignes droictes menées des centres aux circonferences sont égales.

II.

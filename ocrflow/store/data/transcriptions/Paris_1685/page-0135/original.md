## Scholie.

C'eſt pour cette raiſon qu'on appelle omologues les côtez qui ſe répondent dans les figures ſemblables, parce que ces côtez ſont proportionnels les uns aux autres, ou qu'ils ont même raiſon, ce que ſignifie ce mot *Omologue.*

## Theoréme cinquiéme.

Si dans deux triangles, les côtez qui comprennent l'angle du ſommet ſont proportionnels, les deux triangles ſont ſemblables.

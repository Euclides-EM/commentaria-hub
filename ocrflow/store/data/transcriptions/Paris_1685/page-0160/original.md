## Theoréme cinquiéme.

Les arcs d'égale quantité de degrez dans differens cercles ſont entr'eux comme les cercles dont ils ſont les parties.

Cela eſt clair : les degrez ſont les parties proportionneles d'un tout : donc elles ſont entr'elles comme les touts dont elles ſont les parties.

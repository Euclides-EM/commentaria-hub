### An other demonſtration to proue the ſame.

An other demonſtration.

Suppoſe that the number A haue to his halfe an od nũber, namely, B. Then I ſay that A is euenly odde onely. That it is euenly odde needeth no proofe: foraſmuch as the number 2. an euen number meaſureth it by the halfe thereof which is an odde number. Let C be the number 2. by which B meaſureth A

(for that A is ſuppoſed to be double vnto B). And let an euen number, namely, D meaſure A (which is poſſible for that A is an euen number by the definition) by F. And foraſmuch as that which is produced of C into B is equall to that which is produced of D into F, therefore by the 19. of the ſeuenth, as C is to D, ſo is B to F. But C the number two meaſureth D being an euen number: wherefore F alſo meaſureth B which is the halfe of A. VVherefore F is an odde number. For if F were an euen number then ſhould it make B whome it meaſureth an odde{printer-error-correction:euen} number alſo by the 21. of this booke, which is contrary to the ſuppoſition. And in like maner may we proue that all the euẽ nũbers which meaſure the number A, do meaſure it by odde numbers. VVherefore A is a number euenly odde onely: which was required to be proued.

## ¶ The 34. Theoreme. The 34. Propoſition.

[Subhead]
*If a number be neither doubled from two, nor hath to his halfe part an odde number, it ſhall be a number both euenly euen, and euenly odde.*
[/Subhead]

[Margin]
Demonſtration.
[/Margin]

{dropcap:S|lines=4|style=decorated}uppoſe that the nũber A be a nũber neither doubled frõ the nũber two, neither alſo let it haue to his halfe part an odde nũber. Then I ſay that A is a nũber both euenly euen, and euenly odde. That A is euenly euen it is manifeſt, for the halfe thereof is not odde, and is meaſured by the number 2. which is an euen number. Now I ſay that it is euenly odde alſo. For if we deuide A into two equall partes, and ſo continuing ſtill, we ſhall at the length light vpon a certaine odde number which ſhall meaſure A by an euen number.

[Diagram: horizontal dotted line labelled A]

For if we ſhould not light vpon ſuch an odde number, which meaſureth A by an euen number, we ſhould at the length come vnto the number two, and ſo ſhould A be one of thoſe numbers which are doubled from two vpward, which is contrary to the ſuppoſition. VVherefore A is euenly odde. And it is proued that it is euenly euẽ: wherefore A is a number both euenly euen and euenly odde: which was required to be demonſtrated.

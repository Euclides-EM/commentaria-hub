## The 12. Theoreme. The 19. Propoſition.

In euery triangle, vnder the greater angle is ſubtended the greater ſide.

{dropcap:S|lines=3|style=decorated|decoration="foliate ornament"}Vppoſe that A B C be a triangle, hauyng the angle A B C greater then the angle B C A. Then I ſay that the ſide A C is greater then yͤ ſide A B. For if not, thẽ the ſide A C is ether equal to yͤ ſide A B, or els it is leſſe thẽ it. The ſide A C is not equal to yͤ ſide A B, for then (by the 5. propoſition) yͤ angle A B C ſhould be equall to the angle A C B: but (by ſuppoſitiõ) it is not. VVherefore the ſide A C is not equall to the ſide A B. And the ſide A C can not be leſſe then the ſide A B, for then the angle A B C ſhoulde be leſſe then the angle A C B (by the propoſition next goyng before). But (by ſuppoſition it is not) VVherefore the ſide A C is not leſſe then the ſide A B. VVherefore the ſide A C is greater then the ſide A B. VVherefore in euery triangle, vnder the greater angle is ſubtended the greater ſide: which was required to be demonſtrated.

This propoſition is the conuerſe of the propoſition next going before. VVherfore as you ſee, that which was the concluſion in the former, is in this the ſuppoſition, or thing geuen: and that which was there the thing geuen, is here the thing required or concluſion. And it is proued by an argument leading to an impoſſibilitie, as commonly all conuerſes are.

## ¶ The 25. Theoreme. The 25. Propoſition.

[Subhead]
*If from an euen number be taken away an odde number, that which remaineth ſhall be an odde number.*
[/Subhead]

[Margin]
Demonſtration.
[/Margin]

{dropcap:S|lines=4|style=decorated|decoration="foliate pattern"}uppoſe that A B be an euen number, and take away from it B C an odde number. Then I ſay that the reſidue C A is an odde number. Take away from B C vnitie C D.

[Diagram: a dotted horizontal line divided by points labelled A, C, D, and B]

Wherefore D B is an euen number. And A B alſo is an euen number, wherefore the reſidue A D is an euen number (by the former propoſition) But C D which is vnitie, being taken away from the euen number A D maketh the reſidue A C an odde number: which was required to be proued.

## ¶ The 26. Theoreme. The 26. Propoſition.

[Subhead]
*If from an odde number be taken away an odde number, that which remayneth ſhall be an euen number.*
[/Subhead]

[Margin]
Demonſtration.
[/Margin]

{dropcap:S|lines=4|style=decorated|decoration="foliate pattern"}uppoſe that A B be an odde number, and from it take away an odde number B C. Then I ſay that the reſidue C A is an euen number. For foraſmuch as A B is an odde number, take away from it vnitie B D.

[Diagram: a dotted horizontal line divided by points labelled A, C, D, and B]

Wherefore the reſidue A D is euen. And by the ſame reaſon C D is an euen number: wherefore the reſidue C A is an euen number (by the 24. of this booke): which was required to be proued.

## ¶ The 27. Theoreme. The 27. Propoſition.

[Subhead]
*If from an odde number be taken away an euen number, the reſidue ſhall be an odde number.*
[/Subhead]

[Margin]
Demonſtration.
[/Margin]

{dropcap:S|lines=4|style=decorated|decoration="foliate pattern"}uppoſe that A B be an odde number, and from it take away an euen number B C. Then I ſay that the reſidue C A is an odde number. Take away frõ A B vnitie A D.

[Diagram: a dotted horizontal line divided by points labelled A, D, C, and B]

Wherefore the reſidue D B is an euen number, & B C is (by ſuppoſition) euen. Wherefore the reſidue C D is an euen number. Wherefore D A which is vnitie, beyng added vnto C D which is an euen number maketh the whole A C an odde number: which was required to be proued.

## ¶ The 28. Theoreme. The 28. Propoſition.

[Subhead]
*If an odde number multiplieng an euen number produce any number, the number produced ſhall be an euen number.*
[/Subhead]

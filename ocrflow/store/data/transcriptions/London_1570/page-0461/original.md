## ¶ The 31. Theoreme. The 33. Propoſition.

[Subhead]
Euery compoſed number, is meaſured by ſome prime number.
[/Subhead]

[Margin]
Demonſtration leading to an impoſſibilitie.
[/Margin]

{dropcap:S|lines=4|style=decorated|decoration="interlaced geometric ornamental design"}Vppoſe that A be a compoſed number. Then I ſay that A is meaſured by ſome prime number. For foraſmuch as A is a compoſed number, ſome number muſt needes meaſure it (by the 14. definition of the ſeuenth). Let there be a number that meaſureth it, and let the ſame be B. Now if B be a prime number, then is that manifeſt which we ſeeke for: but if it be a compoſed number ſome number muſt needes meaſure it (by the ſelfe ſame definition) Let there be a number that meaſureth it, and let the ſame be C.

[Diagram: three horizontal dotted lines labelled C, B, and A]

And foraſmuch as C meaſureth B, and B meaſureth A: therefore C alſo meaſureth A (by the 5. common ſentence): and if C be a prime number then is that manifeſt which we ſought for. But if it be a compoſed number ſome number ſhall meaſure it: and the like conſideration being had there ſhall at the length be found ſome prime number which meaſureth the number going before, which ſhall alſo meaſure A. For if there be not found any ſuch prime number then ſhall infinite numbers decreſing meaſure the ſayd number A of which the one is leſſe then the other, which is impoſſible in numbers: VVherefore ſome prime number ſhall at the length be found which ſhall meaſure the number going before and which ſhall alſo meaſure the number A (by the 5. common ſentence). Euery compoſed number therefore is meaſured by ſome prime number: which was required to be proued.

### ¶ An other way.

[Margin]
An other demonſtration.
[/Margin]

Suppoſe that A be a compoſed number. Then I ſay that ſome prime number meaſureth it. For foraſmuch as A is a compoſed number, ſome number ſhall meaſure it (by the 14. definition of the ſeuenth). Let the leaſt number that meaſureth it be B. Then I ſay that B is a prime number. For if B be not a prime number ſome number ſhall meaſure it. Let C meaſure it.

[Diagram: three horizontal dotted lines labelled A, B, and C]

Wherefore C is leſſe then B. And foraſmuch as C meaſureth B, and B meaſureth A, therefore C alſo meaſureth A being leſſe then B, which by ſuppoſition is the leaſt number that meaſureth A, which is abſurd. VVherefore B is not a compoſed number, but a prime number, which was required to be proued.

## ¶ The 32. Theoreme. The 34. Propoſition.

[Subhead]
Euery number is either a prime number, or els ſome prime number meaſureth it.
[/Subhead]

[Margin]
Demonſtration.
[/Margin]

{dropcap:S|lines=4|style=decorated|decoration="floral and interlaced ornamental design"}Vppoſe that there be a number A. Then I ſay that A is either a prime number, or els ſome prime number meaſureth it.

[Diagram: two horizontal dotted lines, both labelled A]

For if A be a prime number then is that had which is required. But if it be a compoſed number, ſome prime number ſhall meaſure it (by the 33. of the ſeuenth). Euery number therefore is either a prime number, or els ſome prime number meaſureth it: which was required to be demonſtrated.

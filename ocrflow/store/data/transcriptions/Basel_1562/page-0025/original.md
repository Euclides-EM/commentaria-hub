34. Parallel lini haiſſen / welche in einer ebnen ſteht / vnd ſo man ſy zuͦ baider ſeitten volſtreckt / nimmer mehr einander betreffend / noch zuͦſamen khommend.

[Diagram: pairs of parallel horizontal lines labelled 34]

Nemlich linien / welche ſtehtigs in gleicher weitte von einander gehndt.

## II Petitiones ſeu poſtulata. Das iſt /

[Subhead]
Ettliche ſtücklin / ſo zuͦ diſer kunſt erfordert / vnnd gleich wol nit bewiſen / ſonder als onzweiffelhafft geſetzt werden.
[/Subhead]

[Diagram: two straight lines drawn from a point labelled punct]

[Curated heading level=1 type=postulates: Das erſt buͦch Euclidis]

[Curated heading level=2 type=postulates: Petitio 1.]

1. Von einem jetlichen Puncten zuͦ einem anderen / mag ein geſtracke lini gefürt werden.

[Curated heading level=2 type=postulates: Petitio 2.]

2. Auch mag einn jede gerade lini ſtrackh forttgezogen / vnnd nach gefallen erlengert werden.

[Curated heading level=2 type=postulates: Petitio 3.]

3. Auß einem jeden Centro mag auf einer jetlichen weitte ein zirckel geriſſen werden.

[Diagram: concentric circles about a centre labelled 3]

## III Communes Noticie.

[Subhead]
Gemain erkantnuſſen oder verſtand / Das iſt / Ettliche Puncten ſo zuͦ diſer khunſt dienen / vnnd durch den gemainen verſtand yederman eingegeben vnd bekhant werden.
[/Subhead]

[Curated heading level=1 type=axioms: Das erſt buͦch Euclidis]

[Curated heading level=2 type=axioms: Communis noticia 1.]

1. So ettliche ding einanderen gleich ſind / die ſelbige ſeind auch einander gleich.

Diß ſtücklin / ſambt den volgenden zwayen / wie ſchlecht ſy ja anzeſechen / hatt nit allain groſſen nutz derhalben / das in der Geometrj vil ding dardurch demonſtriert werden / ſonder auch die Rechenkunſt hatt ſy in groſſen brauch / Ja die aller kunſtreicheſte Regell Algebre / ſunſt die Coß genannt / behilfft ſych jr dermaſſen / Das vil exempel on deren hilff khains wegs außgemacht mögen werden. Hab ich wöllen anzaigen / das du ſecheſt / wie in diſen herrlichen khunſten nichts ſo ſchlecht / daß nit ſein gröſten nutz habe / wirſt du forthin offt. Auch bey der 7 vnd 11 des fünfften buͦchs vernemmen.

[Curated heading level=2 type=axioms: Communis noticia 2.]

2. So man zuͦ gleichen dingen gleiche hinzuͦ thuͦt / werden auch die yenige / ſo auß ſollicher zuͦſatzung erwachſen einander gleich ſein.
